# Bienestar Universitario - Universidad Simón Bolívar 🎓🏛️

Portal web informativo institucional para la **Dirección de Bienestar Universitario** de la **Universidad Simón Bolívar** (Barranquilla y Cúcuta, Colombia).

Desarrollado con una arquitectura moderna en **React**, **Tailwind CSS**, y **Node.js (Vite)**, diseñado con estándares de ingeniería de software senior, rendimiento optimizado a 60 FPS, animaciones micro-interactivas y diseño 100% responsivo para computadores y dispositivos móviles (iOS y Android).

---

## 🌟 Características Principales

- 🖼️ **Carrusel de Imágenes Automático en la Cabecera**:
  - Transición automática cada 5 segundos con barra de progreso animada.
  - Soporte de gestos táctiles (*swipe*) en smartphones iPhone y Android.
  - Pausa inteligente en *hover* y controles manuales.

- 🏛️ **Identidad Institucional Oficial**:
  - Cabecera con los logos oficiales en alta resolución: Emblema Universidad Simón Bolívar y Medalla oficial de **Acreditación Institucional en Alta Calidad**.
  - Fondo arquitectónico con la emblemática **Casa de Bienestar Universitario** y patrones curvos en verde institucional (`#006837`).

- 📱 **Navegación Móvil y Menú de Hamburguesa**:
  - Menú lateral *off-canvas* que **se desliza desde la izquierda**.
  - Modo Oscuro / Modo Claro instantáneo (0 ms).

- 📞 **Directorio Interactivo de Contactos (5 Áreas)**:
  - Búsqueda en tiempo real por palabras clave, áreas, teléfonos y servicios.
  - Filtros rápidos por área:
    1. **Salud Integral** (Medicina general, enfermería, Línea Amiga 317 2163682, jornadas Profamilia).
    2. **Desarrollo Humano** (Acompañamiento psicológico, Código Dorado 315 3778669).
    3. **Actividad Física, Recreación y Deporte** (Coliseo Eugenio Bolívar, gimnasio, rumbaterapia).
    4. **Expresión Cultural y Artística** (Casa de la Cultura La Perla, banda folclórica, danza).
    5. **Permanencia y Desarrollo Estudiantil** (Tutorías académicas, bienestar solidario, becas).
  - Botones de acción directa: Llamar por teléfono, escribir a WhatsApp, copiar correo con notificación interactiva y modal de detalles por área.

- 🚨 **Ruta de Atención Código Dorado**:
  - Protocolo institucional de 4 pasos para atención inmediata y confidencial en salud mental y emergencias emocionales.

- 📸 **Galería de Actividades y Eventos del Campus**:
  - Catálogo filtrable por categorías con visor de pantalla completa (*Lightbox Modal*).

- 📍 **Sedes y Puntos de Atención**:
  - Información detallada y geolocalización de Casa de Bienestar (Sede 2), Coliseo (Sede 1), Casa de la Cultura La Perla y Sede 3.

## 🛠️ Tecnologías Utilizadas

- **Frontend**: [React 19](https://react.dev/)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconos**: [Lucide React](https://lucide.dev/)
- **Empaquetador & Dev Server**: [Vite](https://vitejs.dev/)
- **Optimización de Assets**: Sharp (Imágenes en formato WebP ultraliviano)

## 🚀 Instalación y Ejecución Local

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Marlon7700/pagina_electiva_p.git
   cd pagina_electiva_p
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Compilar para producción:
   ```bash
   npm run build
   ```
